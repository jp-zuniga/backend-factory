# Testing

!!! note "Outline"

    How to test code written against this template.

- Running the suite, the services it needs, and the coverage floor.
- Testing a controller end to end versus testing an operation directly.
- Fixtures and factories for users, tokens and authenticated clients.
- Database rules that only fail against PostgreSQL, and testing them anyway.
- Property-based and schema-driven tests with the tools already in the lockfile.
