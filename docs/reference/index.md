# Reference

This section is lookup material: tables you scan for a name, a default, or a
url, not prose you read start to finish.

- **[Configuration](configuration.md)** — every field `ApiConfig` reads,
  grouped by what it configures, with its type, its default, and the
  `.env.example` key that feeds it.
- **[Catalog](catalog.md)** — one table per family the template ships:
  controllers, operations, base models, schema helpers, and every endpoint
  with its url name.

What is *not* here is explanation. If you want to know **why** the
configuration is shaped the way it is, or **how** a controller resolves its
generics into a working endpoint, that lives under [Concepts](../concepts/index.md).
If you want a worked example of using any of this to add something new, that
lives under [Guides](../guides/index.md). This section only answers "what is
its name and what does it do", as precisely as the source allows.
